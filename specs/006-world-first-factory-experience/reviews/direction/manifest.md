# T507 direction mockup sheets (FR-040, FR-041; R03)

Generated by `uv run --frozen --offline python -m art_pipeline mockup --direction direction-X.json --out .` from `tools/art-pipeline`
(compositor T505, concept sprites T506). Each `direction-X/report.json` lists the SHA-256 of every sheet and the gate results:
24 of 24 input gates pass (palette on every sprite, flash on every strip), no lane violations, both directions.

Directions differ only in the world layer (deck, hatch, depot, vein, pip, pop). Machines (F004 smelter run frames), plates (F004
occupied and empty), and cue badges (F004 missing-input as Blocked, storage-full as Faulted) are the same F004 art in both.
Hub label: H-01 "Works" in the main sheets; H-02 "Office" and H-03 "Operations" are in `direction-X/hub-variants/`
(re-rendered through the direction JSON `ui.hubLabel`, `direction-X-h02.json`, `direction-X-h03.json`). Site name "Meridian Works" (S-01).

## Gaps

- Direction-B wall: the compositor has no role for `edge-tile`, so the wall is not drawn. Direction B therefore differs from A only
  in the deck tone, depot and vein. Showing the wall needs a compositor change (outside this task).
- Props (crate, lamp, drum) and `trunk-branch` have no role. Trunks and branches are drawn as palette-colour lanes, not the sprite.
- Stages: the compositor only swaps sprites by role, so the triptych shows hatch only, hatch with deck filler, and deck. There is no
  wall or gantry (World Bible stages 2 and 3).
- Docked card: the UI model has fixed positions and no selection frame on the machine.
- Machine variety: one machine type (smelter) in all locations.
- UI is an approximation (R03 risk): fit is proven on the emulator, not here.
