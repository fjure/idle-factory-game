# Hub attention-dot task (independent reviewer)

This folder holds 16 pairs of images, `pair_NN_X.png` and `pair_NN_Y.png`. Each image is a crop of a game's "Office" hub button at the device's real pixel size, some in grayscale and some under simulated colour-vision filters. In every pair exactly one button carries a small attention dot (a notification indicator); the other has none.

For each pair, answer which image (X or Y) has the attention dot. Look at each image at its real size; do not run code on the images. Give one line per pair: `pair NN / X or Y / sure or unsure / what you saw (where the dot is, how visible)`. Then a short overall note: how easy the dot was to see, and which pairs were hardest.
