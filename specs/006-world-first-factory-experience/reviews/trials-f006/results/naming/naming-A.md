# naming-A (reviewer A)

Machine type is a guess from silhouette: striped block = miner, round gear disc = assembler. State glyph meanings are guesses: pause bars = paused, down arrow into tray = missing input, ring with bar = inactive, hourglass = waiting, stacked lines = storage full. Markers: chevron-in-square above machine = Boosted, lightning-in-square = Overdrive, both side by side = both.

## Hard pairs and overall note

- Miner vs assembler named from silhouette only (striped block vs gear disc); no label seen.
- Hub dot vs no dot on every P3 sheet: the dot is a 1-2 pixel mark; both Office tiles look nearly identical (worst: phoneP deuteranopia 3 vs 7, phoneP grayscale 2 vs 6).
- Shortage marker (pipe junction tile) is named partly by elimination on every P3 sheet.
- emuP tritanopia tile 6: miner with a dark dot instead of the usual glow; named running, unsure.
- State glyphs were separable by shape in all filters (pause bars, down arrow, ring, hourglass, stacked lines); colour not needed. Marker glyphs (chevron vs lightning) separable by shape.
- Selection frame: double outline in grayscale, blue/cyan outline in colour filters; always clear.
