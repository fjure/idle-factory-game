# Ordering (least to most developed)

Cue key: fence style (low post fence < solid low wall < tall glass fence with lamps/crates/extra floor tiles), number of locked "3"/"4" pads (more locked = less developed), number of built machines and empty unlocked pads.

set2 / 09 / ACB / sure / A low fence, rows 2-3 locked "3"; C wall, rows 2-3 built; B tall fence, decor, row 4 machine
set2 / 10 / ABC / unsure / A low fence, locked rows; B wall, row 3 gear plus locks; C tall fence, decor, open empty pads; A and B have similar machine counts, so fence decided

Overall note: Fence style (low post fence, solid wall, tall glass fence with lamps and crates) plus lock counts agreed in nearly every triptych, which made them easy. Hardest were set2 04, 07 and 10, where the panels have few or similar numbers of machines (and in 07 almost none) and the order rested mainly on fence/decor and lock counts.
